# v0.2.0 Upgrade Notes

v0.2.0 is a data-semantics release.

## Key changes

- Distinguishes API `NA` phase from missing phase.
- Makes sponsor chart explicitly "as registered"; no hidden fuzzy matching.
- Adds industry-collaborator extraction.
- Restricts mechanism landscape to eligible therapeutic interventions.
- Excludes obvious control/placebo rows from mechanism analysis.
- Adds mechanism annotation coverage and a review queue.
- Separates ACTUAL historical primary completions from future ESTIMATED candidate completions.
- Extracts `statusVerifiedDate` and `lastKnownStatus`.
- Adds potential stale-record QA flag.
- Adds approximate start-to-primary-completion duration analysis.
- Adds processing schema versioning so v0.1.x → v0.2.0 does not create false change-tracking events.

## Important baseline behavior

The first full run under v0.2.0 will reset change tracking because the processed schema changed.

This is intentional.

That run becomes the new baseline. Future full runs can again produce meaningful `changes.csv`.
